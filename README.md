## 🌟 About MINI MAFIAN MD

> **MINI MAFIAN MD** is a next-generation **multi-number WhatsApp bot** built on [Baileys](https://github.com/WhiskeySockets/Baileys) — the most powerful WhatsApp Web API available. Engineered by **MAFIAN'𝗦 𝗧𝗘𝗖𝗛**, it handles multiple WhatsApp sessions simultaneously, stores credentials securely on GitHub, and reconnects automatically after any disconnection.

## 🛠️ Installation & Setup

### Prerequisites

```
✅ Node.js >= 18.x
✅ npm
✅ A GitHub account (for session backup)
✅ A WhatsApp account
```

### Clone & Install

```bash
# Clone the repository
git clone https://github.com/Med12-q/mini_dentsu_bot_mdien.git
cd mini_mafian_bot_mdien

# Install all dependencies
npm install

# Copy environment config template
cp .env.example .env

# Edit your configuration
nano .env
```

### Environment Variables

```env
# ╔══════════════════════════════════════════╗
# ║     MINI MAFIAN MD — Environment Config  ║
# ║     By MAFIAN'S TECH                     ║
# ╚══════════════════════════════════════════╝

PORT=8000

# GitHub Session Storage (required)
GITHUB_TOKEN=ghp_yourPersonalAccessTokenHere
GITHUB_OWNER=your_github_username
GITHUB_REPO=your_session_storage_repo

# Bot Identity
OWNER_NUMBER=2348122403265
PREFIX=.
BOT_NAME=MINI MAFIAN MD

# Automation Features
AUTO_VIEW_STATUS=true
AUTO_LIKE_STATUS=true
AUTO_RECORDING=true
```

### Start the Bot

```bash
# Standard start
npm start

# With PM2 (recommended for production VPS)
npm install -g pm2
pm2 start index.js --name "MINI-DENTSU-MD"
pm2 save && pm2 startup
```

## 📡 API Endpoints

| Method | Endpoint | Description |
|:---:|:---|:---|
| `GET` | `/` | 🏠 Landing page |
| `GET` | `/pair` | 📱 Pairing interface |
| `GET` | `/code?number=XXXX` | 🔑 Get pairing code for a number |
| `GET` | `/code/active` | 📊 List all active connections |
| `GET` | `/code/ping` | 💓 Health check & active session count |
| `GET` | `/code/connect-all` | 🔗 Reconnect all saved numbers |
